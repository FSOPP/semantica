## Business rules

**`DOM-006-R1`** — A contract violation is never retried.

I: A contract violation is never retried — basis: the code states "contract violations are deterministic failures: re-running the handler cannot change its return type" at `semantica/pipeline/execution_engine.py:395`, and it is enforced at `semantica/pipeline/execution_engine.py:395`
**`DOM-006-R2`** — Inference that only exists through rules is materialised before a native backend query runs.

I: Inference that only exists through rules is materialised before a native backend query runs — basis: the code states "native execution sends raw query text to the backend, which cannot see rules that were never materialized" at `semantica/reasoning/sparql_reasoner.py:536`, and it is enforced at `semantica/reasoning/sparql_reasoner.py:536`
**`DOM-006-R3`** — A reasoning session's rules are immutable for the life of that session.

I: A reasoning session's rules are immutable for the life of that session — basis: the code states "snapshots are taken at session construction so later mutation of the original Rule objects never affects the running session" at `semantica/reasoning/truth_maintenance_types.py:61`, and it is enforced at `semantica/reasoning/truth_maintenance_types.py:61`
**`DOM-006-R4`** — `wasDerivedFrom` is not emitted twice for the same derivation.

I: `wasDerivedFrom` is not emitted twice for the same derivation — basis: the code states "emit wasDerivedFrom only when this used entity is not the same as parent_entity_id, which already carries that triple" at `semantica/provenance/manager.py:1360`, and it is enforced at `semantica/provenance/manager.py:1360`
**`DOM-006-R5`** — An agent's role in an association is recorded, not implied.

I: An agent's role in an association is recorded, not implied — basis: the code states "hadRole distinguishes approved by, generated by and reviewed by for the same agent/entity pair" at `semantica/provenance/manager.py:1290`, and it is enforced at `semantica/provenance/manager.py:1290`
## Process flow

1. A pipeline stage runs and emits provenance [D: semantica/provenance/manager.py:1290].
2. A contract check runs on the handler's return [D: semantica/pipeline/execution_engine.py:395].
3. Rules are snapshotted at session construction [D: semantica/reasoning/truth_maintenance_types.py:61].
4. Rule chains iterate to fixpoint [D: semantica/reasoning/sparql_reasoner.py:893].
5. Inferences are materialised before native execution [D: semantica/reasoning/sparql_reasoner.py:536].
6. A report is read back [D: semantica/explorer/routes/provenance.py:344].

## Invariants

- A deterministic failure never consumes a retry [D: semantica/pipeline/execution_engine.py:395].
- A rule fires at most one productive pass per fixpoint iteration [D: semantica/reasoning/sparql_reasoner.py:893].
